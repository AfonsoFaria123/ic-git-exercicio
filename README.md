# Projeto de Introdução à Computação - Versão A

Este repositório foi criado para realizar os exercícios de Git e GitHub da disciplina de Introdução à Computação.


## Funcionalidades

Este projeto permite praticar os principais comandos do Git.
Também permite aprender a utilizar o GitHub para guardar e atualizar um repositório.


## O que aprendi

Aprendi a utilizar os principais comandos do Git.
Aprendi a criar, atualizar e clonar repositórios através do GitHub.
